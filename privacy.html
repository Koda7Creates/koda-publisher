Koda Publisher · Privacy Policy

Last updated: November 18, 2026

Koda Publisher is a private publishing tool run by Koda Creates. It is used only by the owner of Koda Creates to upload and publish the owner's own short videos to the owner's own accounts on TikTok, Instagram and YouTube. It is not offered to the public and has no other users.

What data the tool accesses

  • Basic profile information of the connected account (account ID, username), so the tool knows which account it posts to.
  • The access token the platform issues after the owner clicks "Authorize". It is stored only on the owner's own computer.
  • The videos, captions and settings the owner chooses to publish.

What the tool does with it

  • Publishes videos the owner has approved, with the captions and privacy settings the owner chose.
  • Marks AI-generated content with the platform's AI label.

What the tool never does

  • It does not sell, rent or share any data with third parties.
  • It does not collect data from other people's accounts, followers or viewers.
  • It does not use the data for advertising or profiling.

Storage and deletion

Tokens are kept in a private folder on the owner's computer and are never uploaded anywhere else. The owner can revoke access at any time in the platform's settings (for TikTok: Settings and privacy → Security → Apps and services), which makes the stored token useless. Deleting the local folder removes all stored data.
