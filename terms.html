Koda Publisher · Terms of Service

Last updated: November 18, 2026

1. What this is

Koda Publisher is a private tool run by Koda Creates. It lets the owner of Koda Creates publish the owner's own original short videos to the owner's own TikTok, Instagram and YouTube accounts. It is not a public service and nobody else can sign up or use it.

2. Use

  • Every video is reviewed and approved by the owner before it is published.
  • Only original content made by Koda Creates is published. AI-generated content is labeled as such.
  • The tool follows each platform's terms, community guidelines and API rules, including posting limits.

3. Platform accounts

The tool acts only on accounts the owner has connected by clicking "Authorize" on the platform's own login page. Access can be revoked at any time in that platform's settings.

4. No warranty

The tool is provided as is, for the owner's own use, without any warranty.
